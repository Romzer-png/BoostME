# 🚀 BoostME – Analyse de performance YouTube

## 📌 Contexte

Projet réalisé dans le cadre de la formation Data Analyst (Wild Code School).

L’objectif est d’analyser les performances de vidéos YouTube afin d’identifier des tendances et de comprendre les facteurs influençant l’engagement.

---

## 🎯 Objectifs

- Réaliser une étude de marché sur différentes niches YouTube  
- Analyser les performances des vidéos (vues, likes, engagement)  
- Créer des visualisations pour faciliter l’analyse  
- Développer une application interactive pour explorer les données  

---

## ⚙️ Contenu du projet

Le projet s’articule autour de plusieurs parties :

- Collecte de données via l’API YouTube  
- Nettoyage et préparation des données (Python / Pandas)  
- Analyse exploratoire  
- Dashboard Power BI  
- Application Streamlit  

---

## 🛠️ Outils utilisés

- Python (Pandas, API YouTube)  
- SQL  
- Power BI  
- Streamlit  
- Git / GitHub
